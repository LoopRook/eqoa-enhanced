# EQOA Enhanced 0.6.0

The mod API (`eqoa/1`) is not frozen yet. Bundled mods and client updates ship in this release; third-party mod authors should wait for the freeze.

- Bag Viewer works without the game's windows: Look at corpse, Take all / Take all but junk, Sell junk near merchants, and Open bank / Deposit / Withdraw near bankers. Buttons grey out when you are too far away.
- Auto-loot (Off / Everything / Everything but junk, per character) with junk marking; it logs its decisions to eqoa.log.
- Mods can replace the corpse, merchant and bank windows (API not frozen).
- Wereoxxs UI is much faster (11.8 to 1.9 ms per frame on a recorded session).
- Item and action APIs for bundled mods; Round Minimap, Map Search and Creature Journal are bundled mods.
- From the vanilla client: mercenary windows take the keyboard, Hardcore characters and memorials, [OG] account restrictions, texture precache on by default, stacked spell bars you can move in Move HUD, auras and armour looks, a buff window, raid lists and Touch Controls.
- Options -> Extended now uses the vanilla client's five groups; the Enhanced page sits in UI.
- Faster and safer testing behind the scenes.
