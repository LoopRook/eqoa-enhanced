# EQOA Enhanced 0.2.2

A fix-up release for mods (including the bundled Wereoxxs UI).

## What's fixed
- **Mods step aside for every game window:** spellbook, quest journal, options, merchant, bank, trainer, blacksmith, auctions, trade, mail and more.
- **The game's item bar stays hidden** when a mod hides the ability bars and you scroll the hotbars.
- **Holding C or R2** no longer brings up the game's chat history while a mod's chat is on, and the minimap stays put.
- **Mods no longer stop after hours of busy chat** (the whole mod UI used to vanish).
- **Mod settings stay with you** when you move or re-extract the game folder; existing settings carry over automatically.
- If a mod ever stops with an error, **the game's own HUD comes straight back.**

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game.
- **New player?** Download **EQOA-Enhanced-0.2.2-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe**. Wereoxxs UI is included in the mods folder; turn it on in Options > Extended > Mods & Addons > Addon Manager.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Native-Addon-Runtime-NOTICES.txt carries the Lua and Dear ImGui notices; existing MIT, OFL and third-party notices remain intact.
