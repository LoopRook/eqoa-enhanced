# EQOA Enhanced 0.4.2

A privacy fix for map search, and a minimap label fix.

## Fixed
- **Map search no longer lists other players.** Players standing near you showed up by name in map search. Search now lists only NPCs and creatures, never players or their pets. Your creature journal never saved players and is unchanged.
- **Minimap hover labels:** hovering over another player's dot called them an NPC. It now says Player, or Pet for a pet.

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game.
- **New player?** Download **EQOA-Enhanced-0.4.2-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe**. Turn mods on in Options > Extended > Mods & Addons > Addon Manager.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Native-Addon-Runtime-NOTICES.txt carries the Lua and Dear ImGui notices; existing MIT, OFL and third-party notices remain intact. Bundled mods come from FrontiersForge (MIT); see bundled-mods/SOURCE.txt for the small EQOA Enhanced patches (weapon-set bar, Modern UI level-60 fix).
