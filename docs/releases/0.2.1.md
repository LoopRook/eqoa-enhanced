# EQOA Enhanced 0.2.1

This update brings in the latest improvements from the original vanilla client. All Enhanced features and mods (including Wereoxxs UI) work as before.

## What's new
- **Ground Fog option** under **Options > Extended > World** (the PS2 look by default, or Exact). Shadows moved to the Characters page.
- **Duels**, with an orange marker on the compass, on servers that turn duels on.
- **Sound no longer cuts out** in big crowds and busy fights, and far-away or blocked creature swings are quieter.
- **Walking while casting** matches the PS2, with natural leg movement.
- **Glowing weapons, crystals, eyes and spell particles** shine as brightly as on the console again.
- **Falling from Sandstorm's boon** no longer hangs in midair behind a loading screen.
- **Master Class rank upgrades** can be bought again.
- On servers that offer them: **group search (LFG), stack auctions and mail to several people at once.**

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game.
- **New player?** Download **EQOA-Enhanced-0.2.1-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe**. Wereoxxs UI is included in the mods folder; turn it on in Options > Extended > Mods & Addons > Addon Manager.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Native-Addon-Runtime-NOTICES.txt carries the Lua and Dear ImGui notices; existing MIT, OFL and third-party notices remain intact.
