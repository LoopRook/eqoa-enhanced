# EQOA Enhanced 0.3.0

More mods, and a way to send us problem reports.

## What's new
- **ARPG UI and Avoid's Modern UI** now run natively, unchanged, alongside Wereoxxs UI. ARPG UI brings health and power orbs and an action tray; Modern UI brings player, target, group and quest panels. Like Wereoxxs, they step aside for game menus. Turn on **one at a time** in Options > Extended > Mods & Addons > Addon Manager. These two mods are not included in the download; get them from their authors and put them in the mods folder.
- **Save problem reports to your Desktop:** press **F3** in game (or use the crash offer at the next start) and choose **Save to Desktop**. You get an EQOA-Enhanced-report zip with your note, a screenshot and the logs, ready to send to us. Your account name, password and Windows user folder are removed, and nothing is uploaded anywhere.
- Mods that save files are safer: writes are batched, and mods can no longer freeze the game through file access.
- Includes all the 0.2.2 mod fixes.

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game.
- **New player?** Download **EQOA-Enhanced-0.3.0-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe**. Wereoxxs UI is included in the mods folder; turn it on in Options > Extended > Mods & Addons > Addon Manager.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Native-Addon-Runtime-NOTICES.txt carries the Lua and Dear ImGui notices; existing MIT, OFL and third-party notices remain intact.
