# EQOA Enhanced 0.7.1

A hotfix for 0.7.0. It carries two fixes and nothing else.

- No crash report leaves your PC unless you send it yourself: no copy is kept for a game server, none is sent at login, a copy an older version left is never sent, and Delete in the crash offer removes every copy. A run cut short without a crash is worded as "did not close normally".
- A mod's tunar Deposit (`eqoa.actions.bank_money`) deposits; it took tunar out of the bank before, and a Withdraw put it in.
