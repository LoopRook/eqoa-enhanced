# EQOA Enhanced 0.2.0

## New: mods
- **EQOA Enhanced can now run FrontiersForge UI mods**, natively and with no emulator. Create a folder named **mods** next to eqoa.exe, put a mod's folder inside, then turn it on in **Options > Extended > Mods & Addons > Addon Manager**. Mods are off until you turn them on.
- **Supported: Wereoxxs UI.** Its ability bars with the game's icons and cooldowns, casting bar, player, target and group frames, buffs, compass, chat and damage meter all work. Other Forge mods are **experimental** for now.
- **Mods can hide parts of the game's own HUD** (ability bars, buffs, compass, chat window, target, group, pet, health, power and experience bars). Everything comes back when you turn the mod off.
- **Press Enter to type in a mod's chat box.** Game pop-ups and menus still get Enter first.
- **Mod window positions, sizes and settings are kept** between sessions.
- If a mod has a problem, the Addon Manager shows it and **addons_error.log in the mods folder** records it.

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game.
- **New player?** Download **EQOA-Enhanced-0.2.0-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe** from that folder. You need your own Frontiers disc image and a server account.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Native-Addon-Runtime-NOTICES.txt carries the Lua and Dear ImGui notices; existing MIT and third-party notices remain intact.
