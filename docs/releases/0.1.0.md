# EQOA Enhanced 0.1.0

Download **EQOA-Enhanced-0.1.0-Windows-x64.zip**, extract the folder and double-click
**eqoa.exe**. You need your own Frontiers disc image and a server account. No
Rust, Python, source checkout, build command or BAT file is needed for the game.

This first Windows x64 release includes the world map, circular minimap, NPC and
group search/guidance, waypoint tracking, quests/coaches/XP camps, improved map
text, remappable keys and optional HUD details. Upstream work through7912c73 is
retained, including character shadows, fishing/GM support and the GM ground-arrival
fix; server-dependent features require support from your connected server.

**Updates come from LoopRook/eqoa-enhanced releases.** The executable follows the
latest published semantic version. Downloads are checked against the release's
size/SHA256 manifest; failed updates leave the existing program usable. In-game
update notes use the fork changelog. Version tags are retained; master is not
published by this workflow.

NPC sightings confirm only what the client receives nearby. Undetected recorded
spawns are not proof of a creature's death. Guidance indicates direction/distance,
not an obstacle-avoiding route. Full Forge parity remains in progress. Moving
groups, zoning and rare-spawn behavior still benefit from live player feedback.

Bug-report submission to upstream is disabled; local logs remain available. The
external combat parser is optional, maintained separately, and not bundled here.
Existing MIT and third-party notices are included; no different license was
selected. SHA256SUMS is provided for the release assets. The raw EXE and update.txt
are updater assets; players should choose the Windows ZIP.
