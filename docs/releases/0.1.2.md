# EQOA Enhanced 0.1.2

Download **EQOA-Enhanced-0.1.2-Windows-x64.zip**, extract the folder and double-click
**eqoa.exe**. Existing official installs update automatically on start or offer
an in-game restart prompt when the release is detected. You need your own Frontiers
disc image and a server account. No build tools or scripts are needed.

This patch release embeds the NPC catalog into the executable:

- NPC search works even if map-entities.json is missing or the game is started from inside the ZIP.

**Updates come from LoopRook/eqoa-enhanced releases.** The executable checks
update.txt against LoopRook/eqoa-enhanced releases, verifying byte count and
SHA-256 before staging. In-game update notices display the changelog diff.

Existing MIT and third-party notices remain intact. SHA256SUMS is provided for all
release assets. The standalone EXE and update.txt are updater assets; players
downloading manually should choose the Windows ZIP.
