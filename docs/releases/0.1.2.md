# EQOA Enhanced 0.1.2

## Fixes
- **NPC search always works now.** Some players found the minimap search came up empty, even for nearby NPCs, because the game couldn't find its NPC list when it wasn't sitting right next to the program. The list is now built into the game, so search works however you installed it.
- **Searching no longer stops you.** Opening the minimap search used to stop your autorun or follow. Now you keep running while you look something up, and typing in the search box won't steer you.

## New
- **New program icon.** EQOA Enhanced now has its own icon in your taskbar and on the program itself.

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game. Nothing to do.
- **New player?** Download **EQOA-Enhanced-0.1.2-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe** from that folder. You need your own Frontiers disc image and a server account.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Existing MIT and third-party notices remain intact.
