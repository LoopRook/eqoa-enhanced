# EQOA Enhanced 0.7.0

The mod API (`eqoa/1`) is a stable candidate: the guard is on and we do not expect breaking changes. The final freeze comes when the API is offered to the upstream client, after upstream has had its say. Mod authors can start building now: see `docs/modding/` (getting started, a starter mod, the full reference).

- A key for the Mods & Addons window: Controls has a new **Mods & Addons** row, on **F10** by default.
- A key does one thing: a mod may use a modifier plus a key the game uses (Shift+Space while Space still jumps); real conflicts free or swap the other control and say so; F3, F11, F12, Escape and a few others stay the client's.
- Bag Viewer sells Sell 1 / Sell stack near a merchant without opening the game's window.
- **Use the game's windows** brings the game's own windows back when a mod replaces them; helper mods (Bag Viewer selling, Take all, Auto-loot) keep working.
- Mods & Addons shows when a mod replaces game windows or answers NPC dialogs; a mod that changes type or asks for new permissions waits for your approval again.
- Safety for mods: slash commands need the command permission; a mod may decline but never accept the game's own Yes/No boxes (only a group invite); map pins need the waypoint permission and are removed with the mod.
- Mail, Auction and Who open the right window from mods; Map Search waits for the Creature Journal.
