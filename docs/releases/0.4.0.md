# EQOA Enhanced 0.4.0

Mod profiles, included mods, a creature journal for the map, and mod fixes.

## What's new
- **Mod profiles:** each character loads its own mods, settings and window layout. A new character can use a shared **Tank, Healer, Melee or Caster** profile (picked from its class) or make its own copy. Manage profiles in Options > Extended > Mods & Addons > Addon Manager.
- **ARPG UI and Avoid's Modern UI are now included** next to Wereoxxs UI. The game adds any missing included mods to your mods folder, even if you update automatically. They stay off until you turn them on. If you had removed one before, it is added back once (still off); delete it again and it stays gone. Included mods also update themselves, but only files you haven't edited.
- **Weapon-set bar in Wereoxxs UI:** turn it on in Wereoxxs's settings; click a set to use it.
- **Creature journal:** the map learns creatures as you play. Every NPC you see goes into your own journal, and map search finds them alongside the built-in list. Only creatures are recorded, never players or pets. Export your journal or import a friend's (also works with Wereoxx's PCSX2 map mod files).
- Mods stay visible while you talk to NPCs and step aside when the full map is open.

## Fixed
- Mod ability bars sometimes missed cooldowns, especially short ones such as Feed.
- Avoid's Modern UI couldn't be turned on at level 60; its XP bars now hide at max level.

## How to get it
- **Already playing EQOA Enhanced?** It updates itself the next time you start the game, and adds the included mods.
- **New player?** Download **EQOA-Enhanced-0.4.0-Windows-x64.zip** (the ZIP, not the .exe file), extract it to a folder, and run **eqoa.exe**. Turn mods on in Options > Extended > Mods & Addons > Addon Manager.

---

Updates come from LoopRook/eqoa-enhanced releases; the game checks update.txt and verifies the download's size and SHA-256 before installing it. The standalone .exe and update.txt are for the auto-updater. SHA256SUMS covers all files. Native-Addon-Runtime-NOTICES.txt carries the Lua and Dear ImGui notices; existing MIT, OFL and third-party notices remain intact. Bundled mods come from FrontiersForge (MIT); see bundled-mods/SOURCE.txt for the small EQOA Enhanced patches (weapon-set bar, Modern UI level-60 fix).
