# EQOA Enhanced 0.1.1

Download **EQOA-Enhanced-0.1.1-Windows-x64.zip**, extract the folder and double-click
**eqoa.exe**. Existing official 0.1.0 installs update automatically on start or offer
an in-game restart prompt when the release is detected. You need your own Frontiers
disc image and a server account. No build tools or scripts are needed.

This patch release fixes the circular minimap and full world map under Render Scales
2x and 4x:
- The circular minimap keeps its composition coordinates, scale, and mask clipping
  at all render scales without shrinking into the upper-left corner.
- The full world map retains complete backdrop coverage, terrain positioning, and
  proper UI quad and grid alignment across all render scales and viewport shapes.
- Hit testing continues to map accurately to physical window coordinates.

**Updates come from LoopRook/eqoa-enhanced releases.** The executable checks
`update.txt` against LoopRook/eqoa-enhanced releases, verifying byte count and
SHA-256 before staging. In-game update notices display the changelog diff.

Existing MIT and third-party notices remain intact. SHA256SUMS is provided for all
release assets. The standalone EXE and update.txt are updater assets; players
downloading manually should choose the Windows ZIP.
