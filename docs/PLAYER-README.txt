EQOA Enhanced {version} - Windows x64

Extract the entire ZIP into a folder you can write to. Keep map-entities.json
beside eqoa.exe. Double-click eqoa.exe and select your locally owned EverQuest
Online Adventures: Frontiers disc image when prompted. Disc data is not included.

Choose your server and enter your account details in the client. Server access
and account registration depend on that server. Your settings and saved accounts
are created locally; this download contains no accounts or player profiles.

Default map controls (remappable in Controls):
  M: world map. N: minimap. F2: search NPCs, group members and places.
  F4: stop guidance. Use the mouse wheel over the minimap to zoom.
  Select a search result to guide toward it. Set a personal waypoint on the
  world map, then choose Track waypoint to follow it.

Mods (FrontiersForge UI mods, run natively):
  Create a folder named "mods" next to eqoa.exe and put each mod's folder in it.
  Then turn mods on in Options > Extended > Mods & Addons > Addon Manager.
  Mods are off until you turn them on. Wereoxxs UI is supported; other Forge
  mods are experimental. Problems show in the Addon Manager and are written to
  the file addons_error.log inside the mods folder.

Release builds check for automatic updates from LoopRook/eqoa-enhanced:
https://github.com/LoopRook/eqoa-enhanced/releases/latest
Updates use this fork's latest semantic release. Keep the map catalog and notices
beside the executable when it is updated. Re-extract the latest complete player
ZIP when its release notes require a catalog update.

Historical NPC locations are references, not proof that a creature is spawned.
Only nearby entities received from the server can be observed live. The map does
not reveal every spawn across the world. Guidance shows direction and distance;
it does not find a walkable route. Full FrontiersForge map parity is unfinished.

The combat parser is a separate optional companion. It is not included or
required to play or use the map.

LICENSE covers the client. FrontiersForge-MIT.txt covers the historical catalog.
SpaceMono-OFL.txt contains the font notice. Native-Addon-Runtime-NOTICES.txt covers
the Lua and Dear ImGui libraries the mod system uses. These existing licenses are retained.
