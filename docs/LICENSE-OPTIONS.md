# Adopted license for EQOA Enhanced 0.4.6

Upstream code stays MIT in `LICENSE`. The owner selected the EQOA Enhanced
License, version 1.0 (`LicenseRef-EQOA-Enhanced`), for LoopRook's new additions
first published in 0.4.6 or later. Read `LICENSE-ENHANCED` for the full terms.
Earlier releases stay MIT as released; existing MIT grants are not withdrawn.
Code published in 0.4.5 or earlier stays MIT even within later releases.
Pre-existing files have plain-prose notices without file-level SPDX tags:
previously published code remains MIT, and only LoopRook's additions first
published in 0.4.6 or later use LICENSE-ENHANCED. Upstream and third-party code
stays under its own license. The new parser README retains its
`LicenseRef-EQOA-Enhanced` tag.
Upstream portions of mixed files remain MIT.

Anyone, including the Excluded Parties, may run an unmodified official release
to play. Clause 3(b) requires recipients distributing covered additions or
derived works to provide complete corresponding source at no charge under the
same license. Clause 3(c) leaves independent addons using the addon interface
under their authors' chosen terms.

Clause 4 names Sandstorm's developers, administrators, operators and staff;
EQOA.Live's team, website and organizations behind them; organizations owning,
operating or developing Sandstorm; and anyone acting for them. The play
exception remains. Have a lawyer review clause 4 before relying on it.
This document is not legal advice; the license text controls.

The license records 2026-11-04 as the clause 4 date, tied to the planned 0.4.6
release. Adoption takes effect when 0.4.6 ships. If the ship date differs, align
the date with the owner's release decision before publication.

Third-party addons, the FrontiersForge catalog (MIT), Space Mono and other
fonts (OFL), and libraries retain their own notices. No game disc data rights
are granted. The custom exclusion makes the covered additions source-available;
do not describe the combined project as wholly MIT or as open source under an
approved open-source license.

Cargo's inherited `license = "MIT"` stays because the footprint checker forbids
license metadata changes. It is upstream package metadata, not the complete
terms for Enhanced additions. Changing it needs a separate policy review.
Release ZIPs include both root licenses and the existing third-party notices.
The copyright holder may continue private development; recipients still have
the source-sharing obligations when distributing covered derivatives.
