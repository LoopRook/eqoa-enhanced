# Dev tools review

**Verdict: changes requested.** The Python checks pass, but process cleanup, package safety, and manifest preservation have material gaps.

## Findings

- **High — timeout leaves descendants running** ([tools/run_gates.py:316](../tools/run_gates.py#L316)). `subprocess.run` kills only its direct child on timeout, not Cargo's compiler/test descendants. The lock is then released, so a later gate or another agent can start a build while the original descendants still use the shared target directory. Ctrl-C can similarly release the lock without explicitly terminating the process tree.
- **High — package output can modify the live configuration** ([tools/make_owner_test_package.py:56](../tools/make_owner_test_package.py#L56), [line 74](../tools/make_owner_test_package.py#L74), [line 91](../tools/make_owner_test_package.py#L91)). `--output` accepts the live `%APPDATA%/eqoa-rs` directory or an ancestor, and `--force` then removes its `play` subtree; with an ancestor and `--fresh-config`, it can remove a `config` subtree. No resolved-path overlap check protects the live source. A config junction under the destination can also redirect writes. This violates the read-only live-config requirement.
- **High — force destroys the existing play folder before the build succeeds** ([tools/make_owner_test_package.py:90](../tools/make_owner_test_package.py#L90)). A bad executable, invalid channel, unavailable catalogue, or release validation error leaves the owner's previous working `play/` deleted. Stage and validate before replacing it.
- **Medium — manifest rewrite changes unrelated bytes** ([tools/update_bundled_manifest.py:127](../tools/update_bundled_manifest.py#L127), [line 163](../tools/update_bundled_manifest.py#L163)). Universal newline decoding followed by Windows text writes converts line endings across all three files whenever any list changes, even files with no list difference. `format_source_txt` also discards any text after the checksum block. The test compares decoded strings and does not catch either case.
- **Medium — scan includes arbitrary untracked/non-mod files** ([tools/update_bundled_manifest.py:23](../tools/update_bundled_manifest.py#L23)). Every non-hidden file except SOURCE.txt is added, including editor backups, temporary files and unrelated root files. A local `arpg_ui/notes.tmp` becomes a shipped, hashed release asset on the next update; the existing fixed allowlists do not establish this broad inclusion rule.
- **Medium — timeout with captured output aborts summary** ([tools/run_gates.py:339](../tools/run_gates.py#L339)). Python supplies `TimeoutExpired.stdout` as bytes even with `text=True`; if a timed-out command emitted output, concatenating it with a string raises `TypeError`, so no FAIL log or summary is written and remaining steps do not run.
- **Medium — multiple round filters are invalid** ([tools/run_gates.py:151](../tools/run_gates.py#L151)). Passing `--filter foo bar` places two positional filters after `--`; Rust's test harness accepts one filter, so the round step fails instead of running the requested filters.
- **Medium — missing safety and failure-path tests** ([tools/test_run_gates.py:113](../tools/test_run_gates.py#L113), [tools/test_make_owner_test_package.py:30](../tools/test_make_owner_test_package.py#L30)). The gate flow test executes only mocked successful non-cargo steps; it does not test command timeout, Ctrl-C, a failed step's exit code, or an actual cargo-step lock lifecycle. Package tests mock the builder and omit failure preservation and live-config overlap. The manifest test checks decoded text, not bytes. Tests have meaningful assertions, but these gaps allow the defects above through.
- **Low — unknown step selection reports success** ([tools/run_gates.py:267](../tools/run_gates.py#L267)). A typo such as `--only path` selects zero steps and prints ALL GATES PASSED with exit 0, misleading a caller into believing a gate ran.

Lock ownership normally prevents removal of an existing lock on acquisition failure; normal exceptions inside the context release an acquired empty lock. A narrow interrupt between `mkdir` and setting `acquired` can leave a lock behind. The parser sums ordinary result lines and counts SKIP lines as requested; real process-tree cleanup and Ctrl-C were not exercised. The paths gate passed with a writable target directory; this is evidence for the repository guard, not proof it detects every possible local path.
