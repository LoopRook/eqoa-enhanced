# EQOA Enhanced mod API: eqoa/1

Round 1 design, 2026-11-08. Implementation target for rounds 2–4; this is not a claim that these APIs exist today. The stability promise begins only after the round 5 audit and owner's release approval.

Owner decisions are in [the plan](../plans/EQOA-MOD-API-PLAN.md). The Lua global and module namespace are `eqoa`; Forge remains a compatibility layer over the same native core. Automation, including botting, is allowed. Files stay inside each mod's own folder; network and process access are excluded. New implementation belongs in fork-owned files; shared files carry neutral hooks only.
