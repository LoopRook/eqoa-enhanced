# EQOA Target of Target

Displays the Target of Target bar directly above the Target panel in authentic EQOA HUD style, complete with target name, health gauge, power gauge, and click-to-assist functionality.

The bar follows the game's target piece: where Move HUD put it, and as large as HUD Scale (and the PC interface's piece size) make it, in both interfaces. At 100% it is drawn exactly as before.
