Files are unmodified vendor assets from the FrontiersForge reference repository, except:
- wereoxxs_ui/wereoxxs_ui.lua and modules/ability_bars.lua add an optional native weapon-set bar using eqoa.WeaponSets; PCSX2 behavior is unchanged without eqoa. MIT permits modification.
- wereoxxs_ui/wereoxxs_ui.lua reuses each window's custom font handle in EQOA Enhanced while the face and size match. MIT permits modification.
- wereoxxs_ui/modules/chat_window.lua scrolls with the game's chat-history keys (R2 held) through eqoa.ChatHistory when it is there, and snaps back to the newest line on release; without eqoa it keeps the stock stick-to-bottom log. MIT permits modification.
- wereoxxs_ui/modules/chat_window.lua builds each chat line with one concatenation. Where the host supports scoped wrapping and colored text, it sets the wrap position once per message list and draws each line with one TextColored call. The original widget sequence is the fallback on older Forge hosts. MIT permits modification.
- avoids_modern_ui/modules/avoids_exp_bars.lua the XP bars hide at max level and line 269 gets a nil guard, since Util.GetExpRequiredForLevel returns nil at level 60. MIT permits modification.
