# EQOA Mana Bars

Displays an authentic blue power gauge under the target's health bar, matching the original EQOA Enhanced HUD extension styling. Group members' and the pet's power bars are the client's own (Options > Extended > UI: Power Bars); keep that option on, since it is what asks the server for everyone's power.

The bar follows the game's target piece: where Move HUD put it, and as large as HUD Scale (and the PC interface's piece size) make it. At 100% it is drawn exactly as before.
